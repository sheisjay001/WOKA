# WOKA - Workplace Health & Wellness App

WOKA is a web application designed to provide personalized health recommendations for workers across all continents and professions. It suggests meals based on local ingredients, appropriate exercises, and sleep habits tailored to specific job types.

## Features
- **Global Coverage**: Recommendations for Africa, Europe, Asia, North America, South America, and Oceania.
- **Job-Specific Advice**: Tailored health tips for Sedentary, Active, Shift Work, and High Stress jobs.
- **Localized Meals**: Suggests meals using ingredients available in the selected region.
- **Holistic Health**: Covers Diet, Exercise, and Sleep.

## How to Run
1. Ensure you have XAMPP (or any PHP server) installed and running.
2. This project should be located in your `htdocs` folder (e.g., `C:\xampp\htdocs\WOKA`).
3. Open your web browser.
4. Navigate to: `http://localhost/WOKA`

## Structure
- `index.php`: The main application file containing the UI and logic.
- `data/health_data.json`: The database of health recommendations.
- `assets/`: Directory for static assets.
